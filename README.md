# README – Summary of Problem 4, 5, 6

This repository contains brief descriptions of the three problems solved.

## Problem 4 – Three Ways to Sum to n

This problem implements three different methods to calculate the sum from 1 to n:

- A loop-based implementation
- A constant-time mathematical formula
- A recursive implementation

The purpose is to compare different algorithmic approaches and understand their time and space characteristics.

## Problem 5 – A Crude Server

This problem introduces a simple backend server that includes:

- Basic CRUD operations for a Product entity
- Input validation
- Error handling
- Logging
- Pagination, sorting, and filtering
- Separation of layers into controller, service, mapper, and routes
- Swagger documentation

The goal is to create a clean and modular backend API structure.

## Problem 6 – Architecture

This problem describes the software specification for a backend module that enables:

- A real-time scoreboard
- Secure user score updates
- API endpoint design for updating and retrieving scores
- A flow diagram that outlines request and update processing
- Security considerations to prevent unauthorized score manipulation

The specification is written so a backend engineering team can implement the module.
